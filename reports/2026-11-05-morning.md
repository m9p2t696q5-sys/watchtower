## 社会现象观察

**1. AI 叙事的重心正从「模型能力」转向「工作流与工具链」。** 今天 GitHub Trending 上 worktrunk（并行 AI agent 的 Git worktree 管理）、claude-mem、spec-kit、pr-agent 集中出现，配合 OpenAI 收购 Pierre 扩充 Codex 工具、TRAE 谈 AI Coding 下半场，说明开发者社区的注意力已经落在「怎么把 agent 编排进日常工程」而非「哪个模型更强」。这可能意味着下一波价值捕获点在工程化中间层，而非模型本身。

**2. 就业端的「薪资预期差」正在公开化、情绪化。** 张雪回应校招起薪 10 万被嫌低、V2EX 裁员帖、副教授聘期考核争议同日出现，指向同一个背景：雇主与求职者、机构与个体之间对「合理回报」的认知正在拉开。值得关注的是，这类话题的讨论方式越来越倾向于道德审判（「傲慢」「制度不合理」），而非具体条件谈判，这似乎反映出议价渠道收窄后的情绪外溢。

**3. 「低门槛复制型生意」的退潮信号在累积。** 幸运咖门店从万店回落至 8000 多家、手机出货量降 19% 且越卖越贵、中国车市「金九银十」消失，三条不同赛道的条目指向相似的处境：靠铺量和低价换增长的模型正在遇到天花板。这可能不是短期波动，而是消费端对「便宜」本身不再敏感、对「值不值」更敏感的结构性变化。

**星尘智能来杰（正面事件）**：在访谈中明确表示机器人的「iPhone 4 时刻」还没到，但可能比想象中更近，并详细拆解绳驱、力控与世界模型的技术路径。可借鉴之处是：在行业普遍提前造势的环境里，公开承认「还没到」反而建立了技术可信度。
