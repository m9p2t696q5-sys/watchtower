**1. AI 服务「故障补偿」正在成为行业惯例，用户对 AI 的依赖已接近基础设施级别。**
DeepSeek 停摆 5 小时后按 API 消耗发放补偿赠金，同时登上知乎、抖音、B 站三个平台热搜。这说明 AI 工具在部分用户的工作流中已具备「停摆即损失」的属性，用户对服务连续性的预期正在向水电煤靠拢。值得关注的是，补偿方案本身成为讨论焦点，可能意味着「AI 服务的 SLA（服务等级协议）」会逐渐从企业客户向个人用户延伸。

**2. 短剧正在吃掉大量用户时长，但围绕它的公共讨论才刚刚开始。**

**3. 消费场景中的「价格合理性」争议频繁出现，公众对定价公平性的敏感度在上升。**
酒店因肖战演唱会从 179 元涨到 2193 元、市监部门回应「明码标价正常」，与抖音双 11 超级补贴、9 月物价走势解读同日出现。一边是促销补贴刺激消费，一边是极端涨价引发不满，两者之间的张力可能反映出消费者对「被合理对待」的诉求正在增强，而不仅仅是价格高低本身。

## 值得关注的人 / 品牌 / 事件

**1. 胖东来「梦之城」项目**
被夸「教科书级施工」，延续了胖东来在公众心中「认真做事」的品牌形象。值得借鉴的是：在一个普遍追求速度的商业环境里，「按标准慢慢做」本身就能成为传播素材和信任资产。

**2. DeepSeek 故障补偿**
停摆 5 小时后按 API 消耗发放赠金，这一做法在国内外 AI 公司中并不常见。它可能预示着一个趋势：AI 服务的竞争正从「模型能力」向「服务可靠性 + 用户关系维护」延伸。对开发者而言，这也是评估 API 供应商时值得纳入考量的维度。

**3. 尊界刹车踏板支架断裂事件**
三部门联合调查通报发布，余承东表态「正义可能会迟到，但永远不会缺席」，尊界官方表示完全服从调查。这是一起涉及产品安全与品牌信任的结构性事件，后续调查结论可能影响消费者对国产高端新能源车的安全认知，值得持续关注。

**4. Anthropic 宣布弃用 Git**
统治编程 20 年的工具被 AI 公司主动放弃，这是一个标志性信号。它未必意味着 Git 会消亡，但可能说明 AI 原生工作流正在重新定义「开发者工具链」的边界。对开发者和工具厂商来说，值得思考哪些习以为常的工具假设正在被挑战。

**5. 中国科学家首次用中国大模型攻克世界级数学难题**
这一成果如果经得起同行验证，可能意味着国产大模型在「辅助基础科研」这一高价值场景中开始展现实质能力。值得关注的是后续是否有论文发表和可复现的验证。
